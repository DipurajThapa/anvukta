Page rhythm

The page is monotonous because every section is the same shape.

Same width, same heading size, same left-aligned text block, same amount of air. The fix is not more decoration — it is varying the shape of each section so the eye has something to measure against.

Only the ground colour changes. Every band is the same height, the same density, and starts with the same heading at the same size on the same left edge. Nine of those in a row and the reader stops seeing sections.

Heights change. Two sections carry photographs. Two are broken by a one-sentence band. One is a grid of boxes, one an accordion, one a left-heavy list with a wide empty margin. The reader now has landmarks.

Rule 1

Never two sections of the same height and density in a row.

Rule 2

A photograph every third or fourth section — no more.

Rule 3

Every dark section is followed by a breaker, never by another dark one.

Rule 4

One section per page may break the grid. Exactly one.
