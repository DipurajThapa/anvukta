## The treatment

`treat.py` applies the brand recipe to every photograph so a mixed set reads as
one library:

1. Greyscale, autocontrast with a 0.5% cutoff at each end.
2. Contrast lifted slightly (default ×1.06).
3. Both ends pulled off the rails (14–238) so nothing clips to flat black or flat gold.
4. **Tritone**, not duotone — three stops:
   - shadows → ink `#0A1721`
   - mid-tones (62%) → slate `#4A545E`
   - highlights → brass `#DFAE63`
   A straight two-stop ink→brass ramp turns every mid-tone gold and the whole
   photograph reads sepia. The cool slate in the middle is what keeps it premium.
5. Luminance-only grain overlay (default strength 7), so the hue is never tinted.

```bash
python treat.py <in.jpg> <out.jpg> [width] --crop 4:5 --bias 0.3 --contrast 1.06 --grain 7
```

`--bias` sets where a tall crop is taken from (0 = top, 1 = bottom). Facades and
skylines want a low bias; water and ground-level scenes want a high one.

## Reproducing

```bash
python fetch-images.py search      # writes candidates.json + candidates/ thumbnails
python fetch-images.py get <id-prefix> <name>
```

`fetch-images.py` requests `license=cc0,pdm` from the Openverse API, so nothing
with an attribution or share-alike obligation enters the set.
